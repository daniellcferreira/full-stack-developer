# Full Stack Developer - C# e React

## Descrição
Este repositório contém projetos do curso Full Stack Developer, utilizando C# no backend e React no frontend. O curso foi oferecido pela Dio e aborda a criação de aplicações web completas com foco em integração de tecnologias.

## Tecnologias Utilizadas
- **Backend:** C# (ASP.NET Core)
- **Frontend:** React.js
- **Banco de Dados:** SQL Server
- **Autenticação e Autorização:** JWT

## Temas Abordados
- Introdução ao C# e ASP.NET Core
- Desenvolvimento de API RESTful
- Conceitos básicos de React.js
- Gerenciamento de estado com Redux
- Conexão do frontend com o backend
- Manipulação de dados com SQL Server
- Implementação de autenticação com JWT
- Deploy de aplicações Full Stack

## Funcionalidades
- Aplicação full-stack com integração entre frontend e backend.
- Exemplo de como utilizar C# com React e SQL Server.
